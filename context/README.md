# Context / 会话上下文

本目录保存**跨会话的工作上下文**：会话交接摘要、进行中的决策、阶段性状态。

与 `design/` 的分工：

| 目录 | 内容 | 性质 |
| --- | --- | --- |
| `design/` | 架构、模块边界、实施方案 | 相对稳定，长期有效 |
| `context/` | 会话摘要、当前状态快照、临时决策记录 | 时效性，反映"现在" |

## 使用约定

- 文件命名：`session-YYYY-MM-DD-<主题>.md`，一个重要工作阶段一份。
- **新会话开始时**：先读 `context/` 下最新的一份摘要恢复前置状态，再动代码。
- **完成一批重要改动后**：写入或更新一份压缩摘要（改了什么、验证结果、遗留事项、环境注意事项）。
- 过期摘要不删除，在文件头部标记「已被 `<新文件>` 取代」即可。
