# 中国省域人文地理演示语料

本目录包含 30 篇为智能体检索演示而编写的综合性学习条目。内容用于展示“自然环境—历史过程—人口与产业—文化景观”的关联，不作为统计年鉴、地方志或学术论文的替代。除明确指出的常识性地理框架外，涉及地方差异的表述均为概括性描述；精确人口、产量、行政沿革、政策和年代问题应另查权威来源。

生成日期：2026-10-19。每篇由省域概览、自然与聚落、人文历史、人口与产业、文化景观、区域差异和检索提示组成。文档为演示语料，不对应单一外部来源。
