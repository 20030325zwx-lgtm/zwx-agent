# 文档目录

本目录用于存放项目级文档，包括测试记录、部署说明、接口调试记录、故障排查记录和其他过程材料。

现有文档：

- [ROADMAP.md](./ROADMAP.md)：功能路线图和进度
- [skills.md](./skills.md)：内置技能说明
- [pdf-parsing.md](./pdf-parsing.md)：PDF 解析说明

建议分类：

- `test/`：测试方案、测试用例和回归记录
- `ops/`：启动、部署、配置和故障排查文档
- `api/`：接口调试记录和调用示例
- `notes/`：临时技术记录和决策说明

架构、模块边界和长期设计文档统一放在项目根目录的 `design/`。不要再新建平级的 `docs/` 目录。
