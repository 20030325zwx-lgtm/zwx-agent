## 近期优先级

1. RAG 评测集 + 混合检索/重排序：先用数据确认优化是否有效。
2. 联网查询引用与安全边界：让实时信息可验证、可控。
3. 工具沙箱与授权：在扩大自动化能力前收紧副作用边界。
4. Skill 最小闭环：先做注册、启停、授权、选择和契约测试，再扩展 Skill 数量。
5. 统一评测与监控：把每次改动变成可量化的质量提升。
