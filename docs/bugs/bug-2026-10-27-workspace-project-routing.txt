问题现象：已绑定包含多个项目的本地工作区，但智能体声称目标目录不存在；提及 aster-mcp 时又被当成普通闲聊。
影响范围：绑定大型目录工作区后，一级目录排序较后、运行环境无 rg，或消息包含代码式项目名的超级智能体请求。
原因：目录树按完整路径排序后截断，深层文件挤掉后续一级目录；源码搜索强依赖进程 PATH 中的 rg；Planner 没有本地项目优先规则；闲聊短路不识别工作区引用。
解决方式：目录树改为浅层优先；rg 不可用时使用有边界且跳过生成目录的 Java 搜索；工作区短语和连字符项目名确定性路由到 coder；绑定工作区引用禁止闲聊短路。
验证结果：新增目录截断、搜索降级、工作区信号及 Planner 路由测试；mvn clean test 共 310 通过、0 失败、1 跳过。
后续注意事项：项目名检测只作为工作区安全路由信号，不新增用户意图类别；普通闲聊仍可短路。
