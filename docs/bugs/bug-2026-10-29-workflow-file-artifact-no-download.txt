日期：2026-10-29
主题：工作流导出的文件产物在运行记录里没有下载入口

问题现象
「每周调研汇总」运行成功后，最后一步显示「文件已导出：调研简报.md」，
但在工作流的运行记录弹窗里只能看到步骤，看不到任何产物，用户以为文件没生成。
本地磁盘也找不到该文件。

影响范围
所有文件类产物（md/csv/txt/json 等）在列表页的运行弹窗与运行记录详情中都不可见；
图片类产物因为走 img 预览所以正常。工作流编辑页的运行详情本来有下载按钮。

原因
产物实际上传到了 OSS（bucket zwx-agent，对象键
workflow/{userId}/{runId}/调研简报.md），接口返回的 artifacts 也带预签名 URL，
但两处弹窗的模板只渲染 <img>，没有为 type=file 的产物渲染下载链接。

解决方式
运行弹窗与运行记录详情都补上「下载 {文件名}」链接：
- 非 file 类型仍显示图片预览；
- 所有带 url 的产物统一提供下载链接（download + 新窗口打开）。
补充 .artifact-link 样式。

验证结果
在运行记录里展开成功的运行，出现「下载 调研简报.md」，href 是 OSS 预签名地址
（含 response-content-disposition=attachment），可用浏览器直接下载。

后续注意事项
- 产物只存在 OSS，本地没有副本；预签名 URL 有效期 2 小时，过期需重新打开页面生成。
- 以后新增产物类型时，记得在运行弹窗里确认是否可下载，不要只在编辑页支持。
