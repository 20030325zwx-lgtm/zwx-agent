主题：原生 select 下拉弹层样式与产品不一致（黑底大字号）

现象
- 素材库、快速生成、分镜、检查器、设置页中的下拉框，点开后是浏览器/系统原生弹层：
  黑底、蓝色高亮、字号约 2 倍，与页面 13px 的控件完全脱节；选项多时还会遮挡相邻内容。
- 触发框本身有边框，但箭头与弹层风格不受 CSS 控制。

影响范围
- 创作模块 16 处下拉（素材库类型/项目、作品排序、首页工作流/目标作品、素材预览分类、分镜场次、
  检查器候选来源、快速生成生成方式/尺寸/工作流、章节工作流、设定记录类型、工作流输入字段），
  以及设置与工作流编辑器 7 处。知识库管理仍有 4 处原生 select（表格内联，未改）。

原因
- 原生 `<select>` 的展开列表由操作系统绘制，`<option>` 的样式在 Chrome/macOS 上基本不生效，
  只能改触发框，改不了弹层；把它当"样式问题"去调 CSS 是走不通的。

解决方式
- 新增 `components/ui/DropdownSelect.vue`：按钮触发 + 自定义 listbox，遵守 `--wb-*` 令牌
  （回退 `--wf-*`/硬编码色，工作流弹窗也能用），支持 v-model、change、键盘（Enter/Space/上下/Esc）、
  点击外部关闭、禁用项、窄触发时菜单最小宽 132px。
- 创作模块全部替换；设置页（模型供应商、权限效果、MCP 认证、桌面运行模式）与工作流编辑器
  （输入字段类型、运行目标项目）一并替换。知识库表格内的内联分类下拉保留原生实现。

验证结果
- 素材库：类型下拉 13px 选项、宽 194px、选中项带勾；选择「图片」后筛选到 14 个素材。
- 键盘：ArrowDown 打开、Esc 关闭。
- 作品排序、分镜场次、素材预览分类（菜单 132px、选项完整）均正常；深浅色均验证。
- 设置/权限页触发按钮渲染正常；模型与 MCP 页的下拉在编辑弹层内，未逐项展开截图。

后续注意事项
- 新增下拉一律使用 `DropdownSelect`，不要再用原生 `<select>`，否则弹层风格会回到系统默认。
- 表格单元格里的极窄下拉如果换组件，需要确认所在容器没有 `overflow: hidden`，否则菜单会被裁切。
