日期：2026-11-03
问题现象：从素材库引用图片创建视频项目后，创作台首帧选择器显示“选择素材”，用户无法确认引用是否保留或随视频请求发出。
影响范围：素材库/创作首页到视频快速生成的跨项目首帧引用，以及生成记录的输入证据展示。
原因：素材选择器只加载新项目内的素材，外部项目素材 ID 虽保留在表单并进入 referenceAssetIds，但没有按 ID回显；任务卡也未展示输入素材快照。
解决方式：新增归属校验后的素材摘要接口；选择器按 ID 回显跨项目素材缩略图与名称；创作台和任务详情展示 referenceAssetIds 快照及供应商受理状态。
验证结果：前端生产构建通过；LkMediaProviderAdapter 定向测试 2 项通过，HTTP 请求体断言 params.images[0] 为首帧短时公网 URL，缺少公网 URL 时不会调用供应商。浏览器走查因本地浏览器权限被拒绝未执行；未触发计费生成。
后续注意事项：不要仅依赖当前项目素材列表解析已有引用；“供应商已收到素材”只能在存在 providerTaskId 时展示。
