问题现象：执行中看不到子智能体工具调用链，操作明细只在结束后可查；“工作中 3 秒”下方还单独出现一行“正在思考”。
影响范围：超级智能体对话执行过程，尤其是并行子智能体和窄屏布局。
原因：工具账本没有子智能体归属，前端只依赖轮询且未消费工具状态变更事件；空回答的思考状态独立渲染。刷新运行中任务时，助手消息可能尚未落库，导致对话没有承载调用链的位置。
解决方式：账本新增 worker_key 并按派工隔离幂等键；工具状态变化发送 SSE 通知，前端即时重载账本并保留轮询兜底；活动事件携带 workerKey，对话中提供全部/子智能体调用链；刷新时为未落库的运行中回答创建临时视图；思考状态与工作时长合并为一行。
验证结果：工具回调归属及变更通知单测、前端浏览器模拟运行中调用状态与刷新恢复测试通过；前后端构建通过，V33 数据库迁移成功，健康接口返回 ok、前端 HTTP 200。
后续注意事项：旧账本记录 worker_key 为空，只能出现在全部视图；历史活动未保存精确时间，旧任务的跨类型排序只可作近似展示。
