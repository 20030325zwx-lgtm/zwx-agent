问题现象：智能体对话仅显示工具执行摘要，无法查看实际调用、参数和状态；刷新后也不能从对话恢复操作明细。
影响范围：超级智能体对话时间线。右侧运行检查器已有账本，但需手动打开且不实时刷新。
原因：前端仅消费 ActivityEvent 摘要，工具调用账本没有接入对话消息。
解决方式：账本审计返回稳定 ID；按 run 加载工具调用到对应回答，运行时轮询并在结束/历史恢复时重载；时间线显示状态、筛选后的参数和返回摘要。
验证结果：前端脱敏/状态单测通过，前端生产构建通过，后端打包通过，后端健康接口返回 ok、前端返回 HTTP 200。
后续注意事项：账本参数和结果是截断摘要；工具调用成功表示回调返回，项目任务自身退出码仍需看返回摘要。
