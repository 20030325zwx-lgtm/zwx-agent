问题现象：画布生成前自动保存请求在途时可能提前提交任务；工作流参数中的素材引用列表不会递归解析，画布下游节点无法读取上游 assetId；视频播放地址还可能被前端重复拼接；节点卡片读取未绑定的 data 变量会在展示已选结果时触发运行时错误。
影响范围：项目创作画布的草稿一致性、整图/从节点运行和视频结果预览。
原因：保存函数未向调用者返回在途请求；WorkflowService.resolveValue 只递归 Map；播放 URL helper 与页面重复处理相对地址。
解决方式：保存请求改为串行且可等待；参数解析增加 List 递归；页面直接使用 API helper 返回的完整播放地址；节点组件保存 defineProps 返回值并通过 props.data 读取。
验证结果：后端编译与画布校验单测通过，前端生产构建通过；运行时端到端在服务重启后继续验收。
后续注意事项：新增参数容器类型时需同步补递归解析测试；任务提交前必须等待草稿 revision 落库。
