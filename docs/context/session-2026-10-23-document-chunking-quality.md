# 会话摘要：文档切片质量改进（2026-10-23）

## 改动内容

- `MyTokenTextSplitter` 在现有 Markdown 切分前解析 HTML 表格，将每条记录转成带列名的文本；展开 rowspan/colspan；保留章节路径并为表格记录添加 `structuredContentType=table-record` 元数据。
- 只处理当前表格的直接行，避免嵌套表格的行被混到外层；HTML 段落和表格之间保留块级分隔。
- README 增加文档解析/切片核验说明与已知限制。
- 新增 `docs/design/2026-10-23-document-chunking-quality.md`，记录质量问题、分阶段方案、当前边界和验证计划。

## 验证结果

- 两个定向测试通过：合并单元格关系展开；长表按完整行进入多个切片。
- 尚未运行全量后端测试或生产构建。
- 此次没有制作或加入截图（用户取消截图要求）。

## 遗留事项

- 既有数据库向量不会自动更新；需手动重建目标文档索引才会使用新切片格式。
- 复杂多行表头、`rowspan=0`、嵌套表格内容、跨页续表、超长单行和 OCR 质量闸门待后续实施。
- 检索/回答侧需增加表格问题证据完整性检查和固定问答回归集。
