# 智能体操作可视化（2026-11-04）

## 改动内容
- 仅改操作可视化，不改磁盘读取权限和终端工具开关。
- 工具调用账本审计增加稳定 ID；超级智能体对话按 run 加载真实调用，运行中轮询并在结束及历史消息恢复时更新。
- AgentTrace 展示工具名称、账本状态、筛选后的关键参数和返回摘要；重复的工具执行摘要不再叠加显示。
- 新增前端字段筛选和常见密钥脱敏测试，以及问题记录。
- 后续反馈修正：工具账本增加 worker_key，工具状态变化主动推送 SSE；子智能体事件携带同一标识，对话提供全部/单个子智能体调用链。
- “工作中”时长与思考状态合并为一行；移动端工具参数允许换行。
- 运行中的 run 如尚无助手消息，刷新后创建临时回答承载实时调用链；结束后由真实历史消息替换。

## 遗留事项
- 参数和返回内容沿用账本已有截断长度，因此超长输入不会完整呈现。
- `SUCCEEDED` 仅代表工具回调返回；例如项目任务失败的退出码仍以返回摘要为准。
- 旧账本记录未携带 worker_key，仅显示在全部调用链；历史活动缺少精确时间，旧任务的事件与工具跨类型排序为近似顺序。
- 未调用真实付费模型；交互行为应使用测试会话进一步检查。
