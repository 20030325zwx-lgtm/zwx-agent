# 部署 0.7.5（执行到此节点感知上游配置变更）

## 背景（用户问题）

「执行到某一步结果不满意，改提示词后重新执行到该节点（依据上一步结果）」——原先：
- 改**目标节点**自身配置后重跑：支持（目标节点始终重跑，上游复用产物）；
- 改**上游节点**配置后重跑：不支持（上游已成功被跳过，修改不生效）。属此前记录的 P2 缺口。

## 本次改动（提交 a2f713e，仅后端）

- `up_to` 计划新增快照比对：已成功祖先与最近一次运行快照比较
  - 提示词（递归上游拼接后的有效提示词）、模型、尺寸/时长、新增参考图（草稿引用 ∪ 素材输入）；
  - 不一致 → 视为过期，重跑；
- 过期沿**内容边**（提示词/图片）向下传播（执行顺序边不传播，纯顺序依赖不因上上游内容变化而重跑）；
- 验证接口返回「检测到配置变更，将重新执行并更新下游：…」警告，前端沿用现有确认弹窗；
- 选中节点始终重跑；未变更的已成功祖先继续复用产物（成本不增加）。
