# 创作台技能选择：分类、搜索与多选（2026-11-05）

## 改动内容

### 选择器
- 新增 `frontend/src/components/creative/SkillPicker.vue`：单个「技能」入口，弹层内左侧分类（全部/导演与分镜/电商/短片，带数量）、右侧技能列表，顶部名称搜索；复选多选，底部「已选 N 项 / 清空 / 完成」。
- 搜索输入时自动回到「全部」分类；`compat !== 'READY'` 的技能展示但不可选。
- 弹层向上展开（对话框位于页面下方），列表固定 268px 高度内部滚动。
- 新增 `frontend/src/components/creative/skillCategories.js` 统一分类文案，技能库页面改为复用。

### 样式
- `DropdownSelect` 增加 `variant="pill"`（工具条胶囊）与 `option.hint`（下拉项次级说明）。创作台的模型、尺寸选择器改用 pill，与「参考素材」「技能」同高同圆角。
- 模型下拉显示「模型名 + 供应商」，触发按钮只显示模型名，避免长文本挤占。

### 数据流
- 创作台状态由单个 `composeSkill` 改为 `composeSkills[]`；本地草稿、sessionStorage 交接均改为 `skills[]`，旧单技能字段仍兼容读取。
- 交接给画布时节点保存 `skillSlug`（逗号拼接，兼容旧逻辑）与 `skillNames`；检查器优先显示中文名称。
- 技能仍只是创作上下文，不自动触发计费生成；后端未改动。

## 验证
- `npm run build` 通过。
- 浏览器实机：分类切换、搜索（「提示词」命中 4 项且分类回到全部）、多选 2 项后按钮显示「2 个技能」并写入草稿、模型菜单显示模型名 + 供应商、技能库页面分类文案正常。
- 修复过弹层列表被裁切且不可滚动的问题（固定高度 + 子项 `min-height:0` + 内部滚动）。
