## 查看方法

可尝试用浏览器打开 `home.preview.html`。若浏览器/工具禁止 file URL，则在仓库根目录通过仅绑定回环地址的静态服务器查看：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/design/prototypes/2026-10-28-ai-workbench
```

打开 `http://127.0.0.1:8766/home.preview.html`；端口被占用时更换端口。服务器只用于预览，不需要启动 Aster 后端，不会自动调用真实模型或流程。完成后停止服务器。

预览包装页包含沙箱 iframe 和样式资源；部分图标/辅助运行时可能依赖网络，不能将独立 HTML 文件误称为保证完全离线的产品。会话专用 Tweak 设计控件可能在普通浏览器中不可用，导航和原型自身交互不应依赖它。

## 设计与交付约束

- 项目、任务、产物是主线；对话、文档、代码、内容画布和工作流是可打开的视图。
- 个人办公、开发和团队业务是长期覆盖方向，不能一次性扩张为全部首版交付。
- 使用 Ant Design Vue + Ant Design X Vue + Vue Flow；保持现有 Vue 3 技术栈，业务组件自有封装。
- 保留 Aster 视觉与轻量工作台布局，不套用整套后台模板，也不直接复制草图里的手写 HTML 作为生产组件。
- 示例状态、项目数量、AI 建议、任务创建与确认均为本地预览行为，不代表后端真实能力或数据。
- 用户没有对最终像素、数据表、数据库打包方案和完整工期逐项签核；接手时依据最新任务指令推进，有技术障碍再具体说明。
