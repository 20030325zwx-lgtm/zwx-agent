## 里程碑 1：工作台一体化收尾（B 阶段完成，先行）

目标：消灭"双层界面"与旧样式残留，产品观感统一。

1. 任务页（SuperAgent）重组进外壳：去掉自带旧头部，会话/项目侧栏并入外壳导航语境；任务=外壳内的"执行现场"对象视图（复用 TaskComposer/RunInspector/ChatRoom，不重写执行逻辑）。
2. 旧页面清理：`Home.vue`、`WorkspaceLayout.vue`、旧 `ModelSettings.vue` 删除；Skill/MCP/记忆/权限页迁入 `--wb-*` 令牌与设置中心样式。
3. 工作区文件面板：任务详情内浏览授权目录内容（复用 `listWorkspaceFiles`），产物与文件同区展示。
4. 仪表盘补项目维度（工作区卡片显示关联会话数与最近活跃）。

验收：外壳内无双层导航；删除文件后全站构建通过；浏览器浅/深主题截图逐页检查；`npm run build:desktop` 通过。

## 里程碑 2：工作流从试点到可用

目标：从"一个硬编码工作流"到"可定义、可编辑、可复用"。

1. 定义/版本拆表：`workflow_definition` + `workflow_definition_version`（V6），运行绑定版本；商品海报迁移为新模型的首个定义。
2. 步骤参数化：步骤输入 Schema → 前端自动生成发起表单（不再只有关键词）。
3. Vue Flow 画布编辑器：先只读视图（定义→节点图）→ 拖拽编辑（节点/连线校验）→ 试运行；编辑保存为新版本。
4. 商品理解步骤激活：视觉模型直连（模型目录 vision 绑定 + Spring AI Media），摆脱 MCP 容器网络依赖。
5. 产物落工作区：海报等产物可写入授权目录（与目录授权打通），并在任务/工作流详情统一展示。

验收：≥2 个可运行工作流；画布编辑保存新版本并试运行成功；产物出现在授权目录。

## 里程碑 3：桌面发布准备

目标：把"能装能跑"推进到"敢发给别人"。

1. 授权管理界面：查看/撤销已授权目录（后端 DELETE 已就绪）；读写授权分级（写=产物落盘）。
2. 本地文件存储适配器：产物与图片不再依赖 OSS（桌面用应用数据目录），OSS 仅网页部署。
3. 升级与数据安全：pgdata 自动备份/恢复、electron-updater 自动更新通道。
4. 发布工程：Apple 签名公证（需开发者账号）、干净 arm64 机器验收清单（安装→首启→配置模型→任务+工作流+授权目录全链路）。

验收：干净机器全链路通过；升级不丢数据；签名包可分发。

## 里程碑 4（穿插进行）：质量与评测

1. 关键链路自动化测试：登录、目录授权、模型解析、工作流引擎（现有 verify 脚本纳入 CI 或本地一键跑）。
2. 工作流接入模型调用轨迹（`agent_llm_call` 同款证据），排障可回放。
