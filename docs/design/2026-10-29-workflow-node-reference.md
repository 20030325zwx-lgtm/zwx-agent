# 工作流节点配置参考与运行机制

日期：2026-10-29。面向使用者的节点说明书；实现细节见源码 `platform/workflow/`。

## 运行机制（一次运行发生了什么）

1. **保存定义版本**：画布改动保存后生成新版本（v1、v2…），运行永远绑定最新版本；历史运行保留当时的版本号。
2. **发起运行**：在列表卡片三点菜单「运行」或编辑器工具栏输入运行参数（如关键词）后开始。
3. **校验**：保存与运行前都做 DAG 校验（不能有环、连线必须指向存在的节点、开始节点唯一且无入边）。
4. **拓扑序执行**：引擎按依赖顺序逐节点执行（无依赖的并行分支按顺序跑）。
5. **参数解析**：每个节点执行前，先把参数里的引用替换为实际值：
   - `{{input.keyword}}` → 本次运行输入；
   - `{{节点key.output}}` → 该上游节点的输出（整体引用保留原文，嵌入文本则替换为字符串）。
6. **状态落库**：每步状态（待执行/执行中/完成/跳过/失败）、消息与输出实时写入运行记录，页面自动刷新。
7. **失败语义**：某节点失败 → 其所有下游标记「已跳过」，整次运行标记失败并显示原因；已完成的步骤与产物保留。
8. **产物**：图片/文件产物存入对象存储，运行详情里可预览；文件类（md/txt/json/csv）提供下载。
9. **模型选择**：模型节点使用「设置→模型」里绑定的对话模型；运行开始时冻结模型版本，执行中改设置不影响本次运行。

## 节点类型与配置

| 节点 | 参数 | 输出 | 依赖与说明 |
| --- | --- | --- | --- |
| 开始 start | 无 | 全部输入（JSON 文本，`{{start.output}}`） | 每个工作流唯一、不可删除、不能有入边；运行输入在这里进入流程 |
| 图片搜索 search_image | keyword | 图片 URL | 优先图片搜索 MCP；未配置时回退 Wikimedia Commons（中文关键词自动译英） |
| 图片理解 image_understand | image、question | 图片描述文本 | 依赖图片 MCP 的 describe_image；不可用时降级为提示文本并标记跳过 |
| 模型对话 llm_text | prompt | 模型回复文本 | 用绑定对话模型；prompt 可嵌入上游输出做二次编辑/总结 |
| 联网搜索 web_search | query | 搜索结果文本 | 依赖搜索 API Key（application.yml search-api） |
| 图片生成 image_generate | prompt、size、model | 图片产物（可预览/下载） | DashScope 文生图（默认 wanx2.1-t2i-turbo）；按张计费；需要 DashScope Key |
| REST 请求 http_request | method、url、headers(JSON)、body(JSON) | 响应体（截断 4000 字） | 非 2xx 视为失败；字面内网/回环 IP 与云元数据地址拦截，域名放行（兼容代理环境）；桌面模式可放行 localhost |
| 数据库查询 db_query | sql | 结果 JSON | 仅单条 SELECT/WITH，最多 200 行、10 秒超时 |
| 文本模板 text_template | template | 替换后的文本 | 纯文本拼接/封装，不消耗模型；模板可混合文字与引用 |
| 文件导出 file_export | filename、content | 文件产物（可下载） | 按扩展名识别 md/txt/json/csv；下载链接带 attachment |
| 海报合成 poster_render | image、copy | 海报 PNG（可下载） | copy 为文案 JSON（标题/副标题/卖点/配色），通常引用模型对话输出 |

## 画布操作

- **新增节点**：从节点右侧输出端口拖到空白处松手 → 在落点弹出类型菜单 → 选择即创建并自动连线；也可选中节点后在属性面板点「添加下游节点」。
- **连线/改线**：拖端口到另一个节点的输入端口连线；拖动已有连线的端点可改接到其他节点。
- **编辑参数**：点击节点，属性面板显示名称、参数与配置说明。
- **删除节点**：属性面板「删除节点」或选中后按 Delete（开始节点不可删）。
- **整理布局**：「自动布局」按层级重排。
- **运行**：工具栏输入运行参数后点「运行工作流」；有未保存改动时会提示先保存。

## 快速示例：「每周调研汇总」

开始 → 联网搜索（`{{input.keyword}} 最新进展`）/ 联网搜索（`{{input.keyword}} 主要挑战`）→
文本模板（拼接两路结果）→ 模型对话（写 Markdown 简报）→ 文件导出（`调研简报.md`，内容 `{{report.output}}`）。
实测 6 步全部成功，产出可直接下载的 Markdown 简报。
