# 视频生成与剧情制作：验收标准

日期：2026-11-01。状态：标准已定义，下面全部待执行，无用例自动视为通过。

本文件与[产品架构](2026-11-01-video-story-product-architecture.md)、[执行计划](2026-11-01-video-story-implementation-plan.md)配套。验收必须记录基线提交、环境、结果及证据，不能只填“功能正常”。

## A. 独立视频与媒体基础

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| VA01 | 上传/转存正常、超限、损坏、伪 MIME 视频 | 正常媒体记录真实尺寸/时长/音轨并可播放；其他明确拒绝、不 READY；分块计算字节上限，临时文件按任务清理 |
| VA02 | 播放请求与鉴权 | 有权限正常请求 200、有效单范围 206、不可满足范围 416；后缀范围与拖动续播正确；跨用户访问拒绝；签名过期可刷新；LOCAL 和 OSS 路径均按启用部署验证 |
| VA03 | 大文件与安全边界 | 使用至少 100MiB、300MiB 本地测试文件，在测试上限允许下验证视频传输；并发 2 个，记录堆/进程峰值；建议初始 JVM 增量堆目标≤128MiB，且不随两档文件大小线性增长；另测重定向私网、超时、超限、异常退出。指标是目标，不是已测结果 |
| VA04 | 模型能力/输入契约 | 文生视频与图生视频各一个实测组合通过；错误模型、时长/分辨率组合、缺首帧、引用无权限、上游不可访问在付费提交前拒绝；未知能力不显示已支持；无原生音频模型不显示保证配音 |
| VA05 | 请求幂等与输入冻结 | 同项目同键同输入返回同任务、只提交一次；同键变更正文/项目/引用顺序冲突；提交后编辑草稿不改变原快照；换绑定不改变在途任务 |
| VA06 | 故障与恢复 | 在受理持久化前后、查询、转存阶段分别注入重启/超时；有 taskId 沿原任务恢复，未知受理进入对账不盲重提；过期 worker 回写被围栏拒绝；INGEST_FAILED 重新转存不调用生成 |
| VA07 | 取消/限流竞态 | 未提交可阻止提交；已提交按供应商能力显示；完成与取消竞争不丢结果；429 按确定受理语义处理；不支持取消不显示“已取消且未计费”；并发不超配置 |
| VA08 | 快速生成用户路径 | 无剧情资料也能创建视频；刷新后继续查看同任务；生成完成后播放/下载/收藏/再生成；原结果保留；加入分镜不产生生成调用；显示未知费用而非 0 元 |
| VA09 | 工作流视频节点 | 图片结果→图生视频→视频素材入库闭环；视频不能接只收图片的端口；跨外部等待后恢复；从节点重跑按冻结输入复用上游，不重生已选关键帧 |

视频转存的内存测试仅统计应用进程并单独记录 ffprobe/ffmpeg 峰值，不把子进程消耗漏掉。首轮部署资源不同可在实施前调整数值并说明依据，不能测试失败后删除性能门禁。

## B. 剧情与分镜

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| SA01 | 分镜/角色/剧本版本与并发编辑 | 已确认版本不可被草稿改写；两个编辑请求后者版本冲突而非覆盖；镜头重排无重复位置；跨项目写入/选片拒绝 |
| SA02 | 变化与素材依赖 | 修改角色参考/动作/关键帧，相关镜头标旧版本；旧候选保留；删除被批次/选片/时间线引用的素材明确拦截或受控保留；新结果迟到不能替换新版本选片 |
| SA03 | AI 拆解与小说来源 | 合法结构产生可编辑草稿；缺字段/未知角色/负时长/超镜头数明确校验；重新拆解显示差异、不覆盖手改；只导入已确认小说内容快照，修改原章节不改变已确认剧本 |
| SA04 | 人工关卡与一致性 | 未确认分镜不能批量投产；需要首帧的镜头未选图不能生成；角色、服装、场景参考可追溯到版本。人工评审逐镜记录人物/服装/场景/动作的可接受或需重做，AI 建议不代替选片 |
| SA05 | 五镜头故障批次 | Mock 注入 2 镜头确定失败；另外 3 个保留成功；只重试失败项，仅新增 2 个生成意图；不因重试重新生成成功项；未知受理项不得参与自动重提 |
| SA06 | 并发、预算和停止 | 并发上限 2 时不超发；重复启动/重启无重复子项；并行预算预占不超上限；停止后不提交待办项，已提交继续追踪；费用未知显示明确，调用次数上限仍生效 |
| SA07 | 候选与选择 | 一个镜头可有多个版本候选；选定使用版本条件；两个标签冲突提示；全任务完成但未选片仍显示待选片，不能标为可导出完成 |

## C. 成片与渲染

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| RA01 | 时间线编辑 | 只引用 READY 且有权限资产；入出点合法；空镜头显式排除；保存/刷新保留顺序和字幕；目标时长按实际裁切计算；不静默拉伸补时长 |
| RA02 | 三片段合成 | 使用不同尺寸/帧率、有声/无声本地样片，统一目标 MP4 并可播放；顺序正确、中文字幕可见、留边/裁切与预览一致；总时长与计划误差≤2 个输出帧或 100ms（取较大者）；音画基准样片偏差≤100ms |
| RA03 | 渲染故障/幂等 | 重复导出同意图仅一个 RenderJob；暂停/重启/超时/磁盘不足有明确状态与可重试；取消能结束子进程；重试不调用视频模型；旧任务完成不覆盖新选定成片 |
| RA04 | 资源及桌面交付 | 无越界文件读写/任意网络输入/字幕参数注入；CPU/内存/时限约束有效；当前任务目录收尾；桌面目标架构实际运行、中文字体与编码可用，记录二进制版本与分发许可；未覆盖平台明确列为未支持 |

## D. 发布门禁

| 编号 | 标准 |
| --- | --- |
| EA01 | 完成一条真实“确认剧本→至少 3 分镜→关键帧/引用→分镜视频→选片→字幕成片→下载”链路。记录模型、任务/批次/资产/时间线/渲染身份及已知费用。受控故障恢复可用 Mock 验证，不能用 Mock 视频替代全部真实供应商证据 |
| EA02 | 回归已有图片生成/图片编辑/海报、小说、素材授权、工作流模板与从节点重跑。空库迁移和现有数据升级都通过；未完成的视频能力保持门禁，不影响图片/小说使用 |
| EA03 | 交付普通用户操作说明和故障恢复说明，区分“重新查询/重新转存/重新生成/重新渲染”；界面无未解释的 UUID/模板语法；报告列出未支持模型能力、平台与手工步骤 |

**V1-A 发布**：VA01–VA09 + EA02/EA03 相关部分。**V1-B 发布**：再加 SA01–SA07。**V1-C 发布**：全部通过，包括 RA01–RA04、EA01。

真实调用验证须有明确授权范围与预算；本次规划不构成真实付费执行。任务完成数、代码行数、截图或“接口返回 200”都不能替代上述门禁。
