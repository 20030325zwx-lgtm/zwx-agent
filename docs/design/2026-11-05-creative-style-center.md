# 创作画面风格中心（2026-11-05）

## 背景

参考成熟图片/视频平台的「风格中心」：把画风拆成 **题材 × 媒介** 的预设，每个预设带一段
专业描述、标签与封面，可按分类/搜索挑选，并支持收藏与最近使用。我们原有能力只有
「写实 / 漫画」两种，且只作用于图片提示词优化。

本次把风格做成一套目录，**图片与视频共用**；视频节点是主要使用方：
- 选中的风格会写进视频提示词的 [风格]/[质感]；
- 不改提示词直接提交时，也会在提交前拼进提示词，选择立刻生效。

## 1. 目录模型（`creative/support/ImageStyleCatalog`）

30 种预设，三种媒介分组：

| 分组 | 数量 | 取向 |
| --- | --- | --- |
| `photo` 摄影风格 | 18 | 跟随原片、自然写实、胶片人像、时尚大片、都市情感、纪实街拍、电影感、悬疑犯罪、武侠古装、科幻写实、风光、产品、美食、复古 CCD、日系清新、夜色氛围、微距、黑白 |
| `cg` 3D 渲染 | 4 | 3D 卡通、3D 动漫、黏土定格、手办模型 |
| `illustration` 插画绘画 | 8 | 漫画、日系动画、国漫古风、水彩、油画、水墨、像素、线稿素描 |

每个风格记录：`code / label / group / category（题材）/ hint（一句话描述）/ tags / accent（封面色带）/
needsReference / rubric（专业锚点）`。`rubric` 只写视觉语言（媒介、造型、光线、色彩、镜头、质感、避免项），
不写具体主体，保证风格与用户描述的内容解耦；`rubric` 不下发前端。

旧编码（PHOTO_MATCH、REALISTIC…COMIC）全部保留，已保存的画布节点不受影响。

## 2. 提示词骨架按媒介分流

- 摄影：主体/环境/镜头/光线/质感 + `【风格锚点】`
- 3D：造型/材质/灯光/渲染/镜头 + `【风格锚点】`
- 2D 插画：媒介/线条/上色/构图 + `【风格锚点】`

新增风格只改目录，不再写整份系统提示词。`REALISTIC`、`COMIC`、`PHOTO_MATCH` 保留各自
原有的独立提示词（历史行为不变）。

## 3. 视频画风的两条注入路径

1. **优化提示词**（`POST /ai/creative/prompts/optimize`，mode=VIDEO_PROMPT）：
   `imageStyle` 非空时在系统提示词追加 `【画面风格】<锚点>`，要求写进 [风格] 与 [质感]，
   不得改变主体、动作、运镜与台词。未选风格则完全不注入（保持自由发挥）。
2. **提交生成**（`CreativeCanvasService` → `WorkflowService.startMediaVideoTask`）：
   画布节点 `data.styleCode` 随 graph 保存，运行图时作为 `styleCode` 参数带入；
   提交前用 `withVideoStyle()` 拼到提示词末尾。用户原文优先：预算不足时降级为
   「<风格名>画风。」，再不够就放弃注记，绝不截断正文（模型上限 500 字）。

`configChangedSinceRun` 同步比较 `styleCode`，改风格会被识别为配置变更。

## 4. 前端风格中心（`components/creative/ImageStyleCenter.vue`）

- 检查器里的触发按钮显示色带 + 名称 + 题材；面板用 Teleport 挂到 body，避免被检查器滚动裁剪。
- 搜索（名称/题材/描述/标签）、分类 Tab（全部/摄影/3D/插画/收藏/最近）、卡片带色带、标签与描述。
- 收藏与最近使用只存 localStorage（`aster.style.favorites` / `aster.style.recent`），不上服务端。
- 需要参考图的风格（跟随原片）在无参考素材时禁用并标注。
- 选中值写入节点 `data.styleCode`，随画布保存；视频未选时为空，图片节点保持原有默认
  （有参考图→跟随原片，否则→自然写实）。

## 5. 接口

`GET /ai/creative/prompts/image-styles`（兼容保留）与 `GET /ai/creative/prompts/styles`
返回同一份目录视图：`code/label/group/category/hint/tags/accent/needsReference/cover`。

## 6. 风格预览图

`frontend/public/style-previews/<code>.jpg`，30 张，由脚本用 DashScope `wanx2.1-t2i-turbo`
按「同一场景 × 各自画风」生成，便于横向比较画风而不是主体差异：

- 人像/电影/悬疑/古风/都市/日系/夜色/黑白/CCD/胶片/时尚/科幻 → 同一石桥场景（古装/未来题材各自换装）；
- 风光、产品、美食、微距、3D、手办 → 各自固定主体；
- 输出 1280×720 → 压到 800px JPEG（单张 40–90 KB，懒加载）；
- `View.cover` 由编码拼出，前端 `<img>` 加载失败时自动回退到色带；
- 单测校验「目录里每个风格都有对应图片」，避免以后加风格漏图。

## 7. 验证与遗留

- 单测：目录规模/分组/标签/旧编码兼容、三套骨架各自的锚点注入、视频注记的可选性与降级拼接。
- 未做：风格预设的缩略图（当前用色带）、风格对「镜头运动/节奏」的预设、
  把风格做成生成参数的显式字段（现在仍是提示词层面）。
