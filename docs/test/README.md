# 测试用例与结果

本目录集中维护可复用的项目级测试场景和人工/自动验证记录。可执行的自动化测试仍以 `src/test/`、`frontend/` 中的测试代码为准；这里记录测试目的、关键输入、预期结果、运行命令和实际结论，方便复核与回归。

## 目录

- [用例清单](cases.md)：稳定、跨版本复用的功能与质量用例。
- [测试结果](results/README.md)：按日期记录执行范围、结果和未覆盖风险。

## 记录规则

- 每个用例使用稳定 ID，修改行为时同步更新自动化断言和用例说明。
- 结果必须写明执行命令/环境、通过/失败/跳过数量；未运行的测试不能写成通过。
- 失败记录实际观察到的行为与日志，不只记录修复后的结果。
- 端到端测试区分模拟数据和真实服务；记录所用数据来源，但不要写入 Token、密码、个人信息或其他秘密。
- 新功能提交应附对应测试；较大的验证批次应新增一份日期化结果文件，并更新结果索引。
