## 追加：下拉框样式统一（同日，用户反馈后）

原生 `<select>` 的展开弹层由系统绘制（黑底、大字号），改 CSS 无法生效。新增 `DropdownSelect`
（令牌化按钮 + listbox、键盘与点击外部关闭、窄触发最小宽度 132px），替换创作模块 16 处、
设置与工作流编辑器 7 处；知识库表格内 4 处内联下拉保留原生。
